# [Plan] 로그인 및 인증 UI/UX 프리미엄 개편

## 1. 디자인 컨셉: Industrial Dark & Glass
현재의 무미건조한 화면을 지우고, '노무Pro'의 전문성을 직관적으로 느낄 수 있는 시각 언어를 도입합니다.

### 🎨 시각적 전략
- **배경**: 깊은 슬레이트 블루(`slate-950`)에서 인디고(`indigo-950`)로 이어지는 딥 그라데이션 적용. 현장의 활기를 나타내는 추상적인 라이트 이펙트 추가.
- **Glassmorphism**: 실제 물리적 카드가 떠 있는 듯한 입체감을 위해 `backdrop-blur`와 미세한 `border-white/10` 적용.
- **강조색**: 
  - **Amber (Safety Yellow)**: 버튼과 중요한 알림에 사용하여 건설 현장의 정체성 확보.
  - **Sky Blue (Trust)**: 신뢰와 스마트함을 전달하는 보조색.

## 2. 주요 개선 사항

### 🏢 아키텍처 및 스타일
- **Tailwind 4.0 최적화**: 깨진 스타일을 복구하기 위한 컴파일러 설정 점검.
- **Typography**: 가독성이 뛰어난 프리미엄 서체(Pretendard) 적용 및 텍스트 위계(Hierarchy) 정립.

### 🔐 로그인 페이지 (`app/auth/login/page.tsx`)
- **브랜드 헤더**: 브랜드 로고(아이콘)와 함께 서비스 명칭의 폰트 디자인 고도화.
- **입력 양식**: 단순한 상자가 아닌, 포커스 시 부드러운 글로우(Glow) 효과가 나타나는 고급 입력 필드.
- **소셜 로그인**: 네이버/카카오 버튼을 픽셀 단위로 다시 디자인하여 전체 디자인 테마와 통합.

## 3. 사용자 경험 (UX) 디테일
- **로딩 상태**: 로그인 시 단순한 텍스트가 아닌 세련된 스켈레톤 또는 마이크로 인터랙션 적용.
- **반응형 디자인**: 모바일부터 대형 스크린까지 일관된 프리미엄 경험을 제공하는 그리드 시스템.

## 4. 검증 계획
1. `localhost:3002/auth/login` 경로의 모든 시각 요소 점검.
2. 실제 로그인 동작 시 UI 피드백(성공/실패 알림) 완성도 확인.
