---

## 🎯 왜 Gmail SMTP가 필요한가?

### Supabase 기본 SMTP의 한계

| 항목 | Supabase 기본 SMTP | Gmail SMTP |
|------|-------------------|------------|
| **하루 전송 제한** | 4개 | 500개 |
| **Naver 도착률** | ❌ 낮음 (스팸 차단) | ✅ 높음 |
| **Gmail 도착률** | ✅ 높음 | ✅ 높음 |
| **안정성** | 보통 | 우수 |
| **비용** | 무료 | 무료 |

**결론**: 프로덕션 환경에서는 Gmail SMTP 필수!

- ✅ 5분의 시간

## 🚀 전체 진행 과정 (5단계)

```
Step 1: Google 2단계 인증 활성화 (2분)
   ↓
Step 2: Google 앱 비밀번호 생성 (1분)
   ↓
Step 3: Supabase SMTP 설정 입력 (2분)
   ↓
Step 4: 테스트 이메일 전송 (30초)
   ↓
Step 5: 완료 확인! ✅
```

## 📍 Step 1: Google 2단계 인증 활성화

### 1-1. Google 계정 보안 설정 접속

🔗 **링크**: https://myaccount.google.com/security

---

### 1-2. 2단계 인증 상태 확인

페이지에서 **"2단계 인증"** 섹션을 찾으세요:

```
┌─────────────────────────────┐
│ 2단계 인증                  │
├─────────────────────────────┤
│ [사용 설정됨] ✅            │  ← 이미 켜져있으면 OK! Step 2로 이동
│                             │
│ [사용 중지됨] ❌            │  ← 꺼져있으면 아래 과정 진행
└─────────────────────────────┘
```

---

### 1-3. 2단계 인증 켜기 (꺼져있는 경우)

**1) "2단계 인증" 클릭**

**2) "시작하기" 버튼 클릭**

**3) Google 계정 비밀번호 입력**
```
본인 확인을 위해 Gmail 비밀번호 입력
```

**4) 전화번호 입력**
```
본인 휴대폰 번호 입력
예: 010-1234-5678
```

**5) SMS 인증 코드 받기**
```
휴대폰으로 6자리 코드 수신
예: 123456
```

**6) 코드 입력 및 확인**
```
받은 코드 입력 → "확인" 클릭
```

**7) "사용 설정" 버튼 클릭**

---

### ✅ Step 1 완료 확인

```
2단계 인증: [사용 설정됨] ✅
```

**3) 맞춤 이름 입력**

```

**4) "생성" 버튼 클릭**

---

### 2-3. 앱 비밀번호 복사

**화면에 16자리 비밀번호가 표시됩니다:**

```
┌─────────────────────────────────────┐
│  앱 비밀번호                        │
│                                     │
│  abcd efgh ijkl mnop                │
│  ────────────────────               │
│  이 비밀번호는 다시 표시되지 않습니다│
│                                     │
│          [완료]                     │
└─────────────────────────────────────┘
```

**⚠️ 매우 중요!**
```
1. 비밀번호를 복사하세요 (Ctrl+C)
2. 메모장에 임시 저장 (공백 포함된 상태로)
3. 나중에 다시 볼 수 없습니다!
```

**복사한 비밀번호 예시**:
```
abcd efgh ijkl mnop
```

**5) "완료" 버튼 클릭**

```

## 📍 Step 3: Supabase SMTP 설정

### 3-1. Supabase SMTP 설정 페이지 접속

🔗 **링크**: https://supabase.com/dashboard/project/ejgsotsviobjfvfqovcj/settings/auth

---

### 3-2. SMTP Settings 섹션 찾기

페이지를 **아래로 스크롤**하여 **"SMTP Settings"** 섹션을 찾으세요.

---

### 3-3. Enable Custom SMTP

**첫 번째 토글 버튼을 ON으로 변경:**

```
┌─────────────────────────────┐
│ Enable Custom SMTP          │
│ [  ] OFF  →  [✓] ON         │
└─────────────────────────────┘
```

---

### 3-4. SMTP 정보 입력

**정확히 아래와 같이 입력하세요:**

#### 📌 Host
```
smtp.gmail.com
```

#### 📌 Port Number
```
587
```

#### 📌 Username
```
your-email@gmail.com

⚠️ 본인의 실제 Gmail 주소로 변경!
예: ryusiyeol@gmail.com
```

#### 📌 Password
```
abcdefghijklmnop

⚠️ 중요: 공백을 제거하고 입력!

복사한 비밀번호: abcd efgh ijkl mnop
입력할 비밀번호: abcdefghijklmnop (공백 제거!)
```

**공백 제거 방법**:
```
1. 메모장에서 복사한 비밀번호 붙여넣기
2. 공백을 모두 삭제
3. 최종 결과 복사
4. Supabase에 붙여넣기
```

#### 📌 Sender Email
```
your-email@gmail.com

⚠️ Username과 동일한 Gmail 주소!
```

#### 📌 Sender Name
```
노무PRO
```

**또는**:
```
노무PRO - 건설 현장 노무 관리
```

### 3-5. 보안 설정 확인

## 🔧 문제 해결 (Troubleshooting)

### ❌ 이메일이 발송되지 않을 때

#### 1) SMTP 설정 오류

**확인 사항**:
```
☐ Host: smtp.gmail.com (정확한 철자)
☐ Port: 587 (숫자 확인)
☐ Password: 공백 제거했는지 확인
☐ Enable TLS: ON
☐ Save 버튼 클릭했는지 확인
```

**재설정 방법**:
```
1. Supabase SMTP 설정 페이지 재접속
2. 모든 값 다시 확인
3. Save 버튼 다시 클릭
```

---

#### 2) 앱 비밀번호 오류

**증상**:
```
SMTP authentication failed
```

**해결 방법**:
```
1. Google 앱 비밀번호 페이지 재접속
2. 새로운 앱 비밀번호 생성
3. 공백 제거 후 Supabase에 재입력
4. Save
```

---

#### 3) Gmail에서 "보안 수준이 낮은 앱" 차단

**확인 방법**:
```
Gmail에서 보안 알림 메일이 왔는지 확인
```

**해결 방법**:
```
1. 앱 비밀번호를 사용하면 이 문제는 발생하지 않음
2. 만약 문제가 생기면:
   → Google 계정 보안 설정
   → "보안 수준이 낮은 앱의 액세스" 허용
```

---

#### 4) Naver 스팸 메일함으로 이동

**확인 방법**:
```
Naver 메일 → 왼쪽 메뉴 → 스팸메일함
```

**해결 방법**:
```
1. 스팸메일함에서 이메일 찾기
2. "스팸 아님" 클릭
3. 다음부터는 받은편지함으로 도착
```

---

#### 5) Rate Limit 오류

**증상**:
```
Too many requests
```

**원인**:
```
Gmail SMTP도 시간당 전송 제한이 있음
(하루 500개, 분당 약 10개)
```

**해결 방법**:
```
1. 5분 대기 후 재시도
2. 테스트는 천천히 진행
```

## 📊 Gmail SMTP vs Supabase 기본 SMTP 비교

| 기능 | Supabase 기본 | Gmail SMTP |
|------|--------------|------------|
| **하루 전송 제한** | 4개 | 500개 |
| **설정 난이도** | 쉬움 (설정 불필요) | 보통 (5분 소요) |
| **Gmail 도착률** | ✅ 높음 | ✅ 높음 |
| **Naver 도착률** | ❌ 낮음 | ✅ 높음 |
| **안정성** | 보통 | ✅ 우수 |
| **비용** | 무료 | 무료 |
| **추천 용도** | 개발/테스트 | 프로덕션 |
