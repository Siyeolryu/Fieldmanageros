## 🎯 주요 사용자 플로우

### 플로우 1: 신규 가입
```
1. / (랜딩) → 이메일 입력 → "무료로 시작하기"
2. /auth/confirm-email → 이메일 확인
3. 이메일 링크 클릭 → /auth/callback
4. /home (대시보드)
```

### 플로우 2: 로그인 후 출근 기록 추가 ⭐ NEW
```
1. /auth/login → 로그인
2. /home → 중앙 + 버튼 클릭
3. 출근 기록 추가 모달 → 정보 입력
4. "출근 기록 추가" 클릭
5. 달력에 반영 확인
```

### 플로우 3: 프로필 관리 ⭐ NEW
```
1. /home → 헤더 프로필 아이콘 클릭
2. 드롭다운 메뉴 → "프로필 설정" 클릭
3. /dashboard/profile → 정보 수정
```

### 플로우 4: 로그아웃 ⭐ NEW
```
1. /home → 프로필 아이콘 클릭
2. "로그아웃" 클릭
3. /auth/login으로 리다이렉트
```
