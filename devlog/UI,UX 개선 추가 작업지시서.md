노무Pro UI/UX 개선 및 기능 추가 작업 지시서
개요
이 문서는 노무Pro 프로젝트의 UI/UX 개선 및 기능 확장을 위한 작업 지시서입니다. 5가지 주요 수정 사항을 아래와 같이 반영해 주시기 바랍니다.

1. 출근 등록 완료 팝업 알림 메시지 개선 (이미지 1)
현상: 출근 등록 완료 시 브라우저의 기본 window.alert이 작동하여 팝업창 상단에 Vercel 호스팅 URL(dev3nomu...vercel.app 내용:)이 그대로 노출되고 있습니다. 이는 전문성이 떨어져 보입니다.
작업 지시:
기본 window.alert 호출을 제거합니다.
이를 대체할 세련된 커스텀 Toast 알림(예: sonner, react-hot-toast 사용) 또는 커스텀 모달 컴포넌트를 띄우도록 수정해 주세요.
제안 문구:
"출근 등록이 성공적으로 완료되었습니다." (권장)
"출근 기록이 정상적으로 저장되었습니다."
2. 출근 기록 시 '시간 단위 / 일 단위' 선택 UI 추가 (이미지 2)
현상: 메인 대시보드 중앙의 '+' 버튼을 눌러 호출되는 '출근 기록 추가' 모달에서 '근무 시간(시작/종료 시간)'만 입력받고 있습니다.
작업 지시:
근무 기록 입력 방식을 **[시간 단위]**와 **[일 단위]**로 구분할 수 있는 탭(Tab) 또는 라디오(Radio) 버튼을 상단에 추가해 주세요.
시간 단위 선택 시: 기존 UI처럼 오전/오후 시작 및 종료 시간을 입력받는 폼을 렌더링합니다.
일 단위 선택 시: 시간 입력 폼을 숨기고, 대신 '공수(예: 1.0공수, 0.5공수)'를 선택하거나 직접 입력할 수 있는 UI를 노출해 주세요.
3. 엑셀 업로드 양식 샘플 다운로드 기능 추가 (이미지 3)
현상: '근로자 정보 업로드' 모달에 업로드 버튼과 안내 텍스트만 있어, 사용자가 엑셀 양식을 맞추기 어렵습니다.
작업 지시:
모달 내 파일 선택기 상단이나 하단 안내 영역에 [엑셀 샘플 양식 다운로드] 버튼(또는 텍스트 링크)을 추가해 주세요.
해당 버튼 클릭 시, 시스템에 정의된 표준 엑셀 템플릿(.xlsx 파일)을 사용자가 다운로드 받을 수 있도록 구현해야 합니다. (샘플 파일은 public 폴더 등에 배치하여 경로를 연결해 주세요.)
4. Home 페이지에 '대시보드 바로가기' 버튼 추가 (이미지 4, 5)
현상: Home 페이지(/home 또는 캘린더 뷰)에서 전체 메뉴가 있는 대시보드(/dashboard)로 이동하는 동선이 명확하지 않습니다.
작업 지시:
Home 페이지의 접근하기 좋은 위치(예: 상단 헤더 우측 또는 하단 네비게이션 바 등)에 [대시보드로 가기] 버튼을 눈에 띄게 추가해 주세요.
클릭 시 대시보드 메인 화면으로 즉시 라우팅되도록 연결해 주세요.
5. 랜딩 페이지를 첫 화면 및 로그인 페이지로 설정
현상: 기존 랜딩 페이지의 이미지가 훌륭하여 서비스 진입 시점에 적극 활용하고자 합니다.
작업 지시:
현재 랜딩 페이지(또는 해당 랜딩 페이지의 메인 이미지/레이아웃)를 서비스에 처음 진입하는 **첫 화면(Root Route /)**으로 설정해 주세요.
또는 해당 뷰를 로그인 페이지의 배경 및 메인 화면으로 통합하여, 사용자가 로그인하기 전에 좋은 인상을 받을 수 있도록 라우팅 및 레이아웃 구조를 재조정해 주세요.
